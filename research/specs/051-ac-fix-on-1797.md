## Hypothesis

Two initialization/conditioning levers ported from the 047 AC-fix work to the cleaner 1797 baseline:
- **Recip-init** (`LOOP_SCALE_INIT=recip`): init each loop layer's attn/mlp scale vectors to `1/(num_loops+1)` so the residual sum magnitude stays ~stable across N passes through shared weights.
- **Iter-embeds** (`LOOP_ITER_EMBEDS=1`): inject a learned `[hidden]` vector per loop pass at loop entry, giving each pass a distinct identity signal.
- **Re-warmup** at loop activation: reloads the loop-active compiled graph from disk into CUDA memory right when `looping_active` flips, preventing mid-run recompile hang.

The 1797 baseline is simpler to compile than the 045 stack (no RECUR_ALPHA, no loop_resid_mixes), so these levers should have less interaction noise.
