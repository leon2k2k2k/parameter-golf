## Background

Our current baseline runs with `RECUR_ALPHA_ENABLED=1`, which scales each loop
carry by a frozen vector `[1.5610, 1.8531, 2.1320]` (Spec 037). These values
were learned in an earlier sparse alpha-beta experiment and then frozen — they
are not re-trained here. PR #1797 used the rounded version `[1.56, 1.85, 2.13]`
(Spec 036).

With `RECUR_ALPHA_ENABLED=0` the carry passes between loop iterations at natural
scale — no frozen bias. This is the "plain loop" that predates the alpha-beta
experiment, and is more neutral with respect to any assumptions baked into the
frozen values.

## Hypothesis

The frozen carry values may be helping, hurting, or neutral relative to the plain
loop. This ablation isolates that contribution cleanly against the 039 baseline
(which has RECUR_ALPHA_ENABLED=1).

## Acceptance

- **Frozen carry is helping**: 039bK pre-quant > 1.0651 (worse than baseline)
- **Frozen carry is neutral**: 039bK pre-quant ≈ 1.0651 (within ~0.0003)
- **Frozen carry is hurting**: 039bK pre-quant < 1.0641 (beats baseline — frozen carry was a drag)

## What this tells us

If frozen carry is hurting, removing it is free BPB — and future LR schedule experiments should run with RECUR_ALPHA_ENABLED=0 as the new baseline. If it's helping, we should consider re-learning it rather than using stale frozen values.
