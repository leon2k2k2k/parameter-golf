# Spec 250 — PR #1953 verbatim + LeakyReLU² slope 0.5 → 0.3

**Date:** 2026-04-30 (deadline day)
**Idea:** `research/ideas/1948-leakyrelu2-slope-0.3.md`
**Lineage:** PR #1953 (andrewbaggio1, bd495c13, 1.05855 3-seed) — current public frontier.

## Hypothesis

Porting PR #1948's empirically validated activation-slope finding
(LeakyReLU² slope 0.5 → 0.3, −0.00073 BPB isolated on #1851 line) onto
PR #1953's V21 stack will land below #1953's 1.05855 3-seed mean. The slope
shift is purely numeric (5 sites: 1 eager + 4 Triton kernel constants) on
otherwise verbatim #1953 code, so transfer risk is bounded. Expected post-TTT
BPB: 1.0578 ± 0.0006 (3-seed).

## Baseline

PR #1953 @ **1.05855** (3-seed mean, std 0.00030). Per-seed: 42 → 1.05825,
0 → 1.05846, 1234 → 1.05895. Eval times 430–513s; train ~596s; artifact ≤
15.99 MB.

## Expected Δ

**−0.0007 ± 0.0005** vs #1953. Confidence medium: #1948's slope=0.3 was
measured on a different base (#1851/#1938) but at the same activation site
(`leaky_relu(x, slope).square()` in the MLP). The TTT regime in V21 is
strictly stronger than #1948's base, so absorption risk exists; counter-
weight is that the slope changes the per-neuron gradient distribution which
TTT cannot fully back out.

## Accept criteria

- 3-seed mean post-TTT BPB **< 1.05825** (≥ −0.0003 below #1953, accounting
  for std≈0.0003).
- All seeds clear 600s train cap, 600s eval cap, 16 MB artifact cap.
- All seeds pre_quant BPB within 1σ of #1953's 1.06187 (sanity: training
  trajectory unchanged in shape).

If 3-seed mean lands in [1.05825, 1.05895] = wash, no submission gain over
#1953 verbatim — fall back to submitting #1953 unchanged.

If 3-seed mean > 1.05895 = regression, kill.

## Hardware ladder

- **Mini (2×H100):** SKIP. Justification: code change is a 5-site numeric flip
  on PR #1953's publicly validated 3-seed commit (bd495c13). The change does
  not alter shapes, dtypes, kernel grid, autotune surface, or compile graph
  structure — only multiplicative constants inside the kernel and eager paths.
  A 2×H100 mini cannot exercise the V21 + 600s wallclock + TTT regime that's
  the actual signal; it would only verify "kernel still compiles and trains
  for a few hundred steps," which is implicit in the syntax check + the
  identical-structure edit.
- **Official (8×H100):** 3 seeds (42, 0, 1234) matching #1953's seeds for
  direct per-seed comparability. Each seed = 600s train + ~470s eval.
